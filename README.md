# CASSIE Perfumes · Website Draft 1 — "Noir Atelier"

Homepage design draft for the CASSIE Perfumes B2B website redesign, prepared by The Digital Elites.

Live preview: https://sami9188.github.io/cassie-draft-1/

Direction: dark luxury, champagne-gold accents, Cormorant Garamond + Jost. Manufacturing (OEM / ODM / private label / bulk export) leads; the own-brand shop is a secondary section.

Sections: hero with brand film, stats, services, 6-step manufacturing process, interactive bottle & packaging configurator (feeds the RFQ), capabilities, quality & compliance hub, export markets, portfolio, 4-step RFQ form, sample kit, about, CASSIE Fragrances (secondary), insights, contact.

Notes: static HTML/CSS/JS, no build step. Product images and the hero video are loaded from cassieperfumes.com. Figures, MOQs, certifications and portfolio cases are placeholders pending CASSIE approval. Forms are demo-only (Zoho CRM in production).
